# Five volunteer issue ideas

Draft ideas only; no issues have been published.

1. **Test notification reliability across Android manufacturers.** Record Samsung/Pixel/Xiaomi model, Android version, notification/exact-alarm/battery settings, expected time and actual time. Verify reboot and denied-permission behavior without publishing personal records.
2. **Review Arabic/Urdu/Malayalam/Hindi Android interface wording.** Check the first-run import guidance and permission explanations on a 390px phone in both themes. Interface wording only; do not translate religious text.
3. **Exercise share-sheet and file-picker backup round trips.** Try plain and encrypted files with Android Files and common chosen storage destinations. Verify wrong-passphrase and cancelled-picker behavior preserves records.
4. **Capture store-ready screenshots and a feature graphic.** Use synthetic profiles, English/Arabic and both themes. Supply 1024×500 feature art with no new religious text, private data or unlicensed imagery.
5. **Audit accessibility on a physical Android phone.** Check TalkBack labels, focus after permission return, large font scaling, contrast and hardware Back. Include a reproducible sequence and a synthetic profile.

## CI and release limits

GitHub API access currently returns `Forbidden`, so PR creation and an actual CI run URL cannot be obtained here. Opening the pushed branch as a PR triggers `.github/workflows/android.yml`, which builds/uploads a debug APK. Workflow page: https://github.com/riyadhali66/Istiqamah/actions/workflows/android.yml. A workflow-page URL is not a passing run URL.

Tag-only signing requires the four maintainer secrets and an explicitly created `v*` tag matching package.json. The workflow verifies signatures and publishes APK/AAB/checksums/changelog with write permissions confined to its tag-only publish job. The keystore is temporary on the runner and deleted afterwards. Keep the real release keystore/passwords forever; no production key has been supplied or generated by this work.

Physical-device verification remains required for notification delivery after reboot/Doze/OEM battery restrictions, Android permission screens, share targets/file chooser and orientation sensor availability.
